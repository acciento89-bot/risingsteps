# Rising Steps completion design

User intent: finish the existing native Unity game autonomously, matching supplied fantasy concept, then provide an installable internal TestFlight build and signed Android package. The user is away until18:00 and explicitly requested autonomous implementation without stopping at analysis. That instruction overrides generic staged reapproval; existing written request, MASTER-PLAN, ART-DIRECTION and ledger are the product brief. No public publishing.

## Experience
Bright sky adventure:12 ordered island landings per realm, larger temple/portal destination. Preserve camera yaw controlled by the player; follow position smoothly without forcing yaw. Three authored pattern realms with distinct meadow/waterfall/temple dressing. Normal jumps are reachable with comfortable margins; immediate recovery at the last landed island. Portal completion offers next unlocked realm or replay. Home shows realm progress and contextual Shop/Daily/Style; these never obscure active jump route.

## Rules and persistence
Versioned local profile schema1, key `kamilunavo.risingsteps.profile.v1`; no previous persistent profile exists in current source. Save wallet, ownership/style, unlocked realms, best stars, active realm/step, elapsed active-play time/falls/perfects, settings, daily dates/streak/challenge. Normalize malformed arrays/ranges; unknown schema fails conservatively rather than destroying stored data. Atomic local profile serialization; save on landing/purchase/day claim and lifecycle suspension. Realm/step ranges0..2/0..12. Ordered landings award10+2*step crystals, +5 Perfect; duplicate landings award nothing. Perfect landing uses center horizontal distance<=.8. Realm stars:1 completion,2 without fall,3 without fall and active elapsed<=180 seconds. Completing a normal realm unlocks the next; replay remains available.

Daily claim100 crystals plus10 per successive UTC-day streak increment, capped at160 (streak7). Duplicate/earlier day cannot grant. Daily challenge is a dated12-step route using one of the unlocked realms; completing with>=8 Perfects awards75 once for the current UTC date. In-flight old-date completion cannot mint a current-day bonus. Styles0–3 earned at0/75/150/250 crystals, persistent ownership; cancel/locked selection never spends. Achievements track first realm, all realms,12 Perfects and daily streak; these are local progress, not a network leaderboard.

## Controls and UI
Portrait first, responsive safe-area and>=48 logical-point hit targets; tablet/landscape layout supported without recreating the scene or losing progress. Joystick left, Jump right, contextual retry/settings away from jump path. Labels and transparent layout backgrounds do not intercept camera touch; gesture ownership survives joystick+jump+camera simultaneous input. Modal/native overlay and app suspension pause control/active timer; stale jump input is cleared. Settings provide DE/EN, sound/haptics, reduced motion and high contrast. Reduced motion suppresses bob/pulses/orbit transition embellishments, not player-owned camera rotation.

## Art and game feel
Use concept as visual reference only, never full-screen static gameplay replacement. Real colliding3D islands use authored irregular grass/rock meshes, gold route rims/pads, vegetation and noncolliding waterfalls/clouds. Animated stylized brown-haired green-hoodie runner replaces capsule renderer; collision controller remains invisible. Temple/portal is an actual destination focal point. Generated raster sky/terrain/foliage textures may support authored meshes; committed into Assets with import settings/licensing/provenance. Reuse licensed Barlow font/license for readable interface, custom rounded panels/icon geometry matching fantasy palette. Sound/ambient loop, jump/landing/Perfect/fall/UI cues, iOS/Android haptics and portal/landing VFX. No visible default Unity capsule/cylinder demo art.

## Optional commerce
Cosmetics/convenience only, no mandatory or forced ads. Keep earned styles/free realms playable. After core/art pass, integrate native IAP using the verified Perfect Drop adapter pattern with own product IDs and receipt replay/restore safety; optional rewarded test videos only if own AdMob IDs/config can be established. No copied Perfect Drop app IDs, fake real-money fulfillment or live earnings claim. Server catalog, consent/privacy URL and actual sandbox/reward completion remain explicit gates, never simulated success.

## Validation/delivery
Pure tests cover save normalization, daily rollover/replay, stars/unlocks/style ownership and physics-derived reachability. Runtime tests drive real joystick/jump/controller landing callbacks, check fall/retry/modal pause/save/reload, daily guard and visible UI raycasts. Capture native iPhone and available official Duo poses; blocked poses are recorded as blocked, no fabricated evidence. Functional time-capture probes do not measure FPS. Separate30-minute real-time soak, native build/signature and target manifest checks. Internal TestFlight upload/process/tester assignment and signed Android with existing central key. Physical install/thermal/sandbox validation require actual device/user; do not label complete RC without them. Full source main backup verified before generated cache cleanup.
