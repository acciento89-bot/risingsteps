# Rising Steps — Production Store Metadata

## Experience title
Rising Steps

## Short description
Climb higher before the steps disappear. Chain clean landings, build streaks, beat your personal best and unlock cosmetic styles.

## Full description
Rising Steps is a fast vertical survival platformer built around one clear challenge: keep climbing before the steps below you disappear.

Read the next reachable step, move with precision, chain Clean and Perfect landings, and push your personal best higher each run. Difficulty rises as the climb continues, with faster pacing, tighter routes and changing altitude environments.

Features:
- visible third-person avatar throughout gameplay
- fast retry loop
- personal-best and streak chasing
- daily rewards and rotating challenges
- unlockable trails, landing effects, step themes and environment themes
- touch, keyboard/mouse and controller support
- optional reduced-motion setting

Monetization is limited to cosmetics, revive/temporary assistance and cosmetic currency acceleration. Competitive height is never directly purchasable.

## Genre / audience
- Genre: Platformer / Obby / Survival
- Session length: short repeatable runs
- Audience: general Roblox audience
- Social requirement: none
